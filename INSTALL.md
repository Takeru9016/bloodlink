# INSTALL — environment setup

## Prerequisites
- Flutter SDK (stable channel) — FVM recommended for version pinning
- Firebase CLI: `npm install -g firebase-tools`
- FlutterFire CLI: `dart pub global activate flutterfire_cli`
- Xcode (iOS) / Android Studio + SDK (Android)

## Creating the project (one-time)
```bash
flutter create --org com.yourstudio.bloodlink --project-name bloodlink --platforms=ios,android --description "Blood donation & request platform" bloodlink
cd bloodlink
```
Then copy in this repo's `CLAUDE.md`, `docs/`, `.claude/`, `prompts/` on top of the generated Flutter project.

## Firebase link
```bash
firebase login
flutterfire configure   # select bloodlink-dev when prompted
```

## Dependencies
```bash
flutter pub add flutter_riverpod firebase_core firebase_auth cloud_firestore firebase_storage cloud_functions firebase_messaging google_maps_flutter geolocator go_router
flutter pub add --dev freezed_annotation json_annotation build_runner freezed json_serializable riverpod_generator
```

## Running
```bash
flutter run                       # local dev, connects to bloodlink-dev
flutter analyze                   # lint — must be clean before any commit
flutter test                      # unit/widget tests
flutter pub run build_runner build --delete-conflicting-outputs   # after adding/editing freezed or riverpod-generated code
```

## Deploying backend changes
```bash
firebase deploy --only firestore:rules
firebase deploy --only functions
```

## Config notes
- `lib/firebase_options.dart` (generated by `flutterfire configure`) is safe to commit — it's client config, not secrets.
- Any Cloud Function secrets go through `firebase functions:secrets:set`, never hardcoded.
